2.2 Exploitation of public port timetable data

Public timetable information for Finnish ports is available to all without login with NEMO in the Go to Arrivals and outputs view.

Port timetable data include information on ship Port calls: the estimated and actual arrival and departure of vessels; basic information and the state of the Port call.

Go to public port timetable information:

  • open the browser and go to the address mnsw.mnsw.fi

  • Go to Port Start view from main menu and press Go to Arrival and Departures view

Filter List

The schedule view has a filter function with which you can use filters limit Port calls to be displayed:

  • Vessel IMO number- to be written input field

  • Name of vessel- to be written input field

  • Port code — LOCODE code

  • Port call status- pre-selected the list of values defined;

    • Expected to arrive

    • Arrived

    • Departed

    • Cancelled

  • ETA- Estimated time of arrival of the vessel, in form dd.mm.yyyy

  • ATA - Actual Time of Arrival, in form dd.mm.yyyy

  • ETD — Estimated Time of Departure, in the format dd.mm.yyyy

  • ATD — Actual Time of Departure, in the format dd.mm.yyyy

Sort of results

The entry and exit lists have a sorting function. Results can be obtained sort according to alphabetical order, dates and times in ascending or descending order. Default lists are arranged in ascending order according to time of arrival or departure - estimated or actual, whichever is valid.

Digitraffic Public interface

The Maritime Public Integration Interface (REST / JSON) will be published Digitraffic. The interface provides the information described below From ships arriving and departing to Finland, the interface is free usable for different uses of stakeholders. Like this all operators have access to the same timetable information regardless of: whether they have access rights to NEMO. This also means: your organisation Port calls notified to NEMO shall be transmitted: Digitraffic. This will make them part of port transport open to all timetable information.
