2.1 Use of NEMO

2.1 NEMO channels

NEMO can be used for organisational needs and technical environment via one or more channels. Available are:

  • National Port API- Port calls, to search for information and vessel data in Finland

  • Browser interface- NEMO graphic user interface without system integration.

The channels are based on the same data model and the same codes. However, available data and activities may vary: by channel and access rights.

Select a channel suitable for your organisation

National Port API

Select a national port API when your port wants to receive and make direct use of NEMO's data in their own systems. Interface with port services vessel data can be integrated into port operations, for example systems.

The port organisation may carry out the interface integration itself, or use the Data Service Provider (DSP) service provider. DSP works on behalf of the port organisation.

DSP does not have automatic access to the port organisation's data and cannot create the organisation's interface credentials. The port organisation must be registered in NEMO and activate the API connection. The port organisation is responsible for secure handling of Client ID and Client Secret and for securely providing them to the DSP in use.

Go to the Technical Port API of the Notifier's newsletters: Integrate Suomen Maritime Single Window (NEMO) - National API - Port API

Browser interface

Select browser interface if your organisation does not need integration into their own systems.

In the browser interface, port organisation users can: review Port calls to and from their ports; notifications and use the information provided in them.

The port organisation shall not be responsible for reporting port calls. Port can send WAR, ATA or ATD notification only if the transmission of that notification is delegated to the port.

Go to the browser interface at mnsw.mnsw.fi.

Nemon interface

NEMO interface has common navigation elements, settings and system messages. Activity-specific work phases are described: separate instructions.

Go to the user interface at mnsw.mnsw.fi.

Navigation

After you log in, you'll see NEMO's front page. Go to different views from the main menu. Change of organisation, settings, support site and check-out can be found in the Menu menu.

Date Time fields

The presentation of dates and times can vary from one you use by browser, operating system and language settings.

For example, the date may be presented in form DD-MM-YYYY or YYYY-MM-DD and Time format 13:45 or 1: 45 PM. The layout of the date and time dialog windows may also vary by browser.

The differences are usually due to browser or device settings, not Nemon Action.

If the function you have at your disposal has to modify the date or the time field, you can select the value of the calendar or clock icon With help. Using the icon reduces the effect of the wrong format errors.

Quick Messages

The user interface may show short instant messages from the action made result or situation requiring attention. Quick message may be related e.g. search, amendment of the regulation, processing of data, or the operation of the system.

One of the most common quick notifications:

  • Missing information- a mandatory field is not filled. Complete information before saving or This is the case.

  • Invalid information- the field is invalid or conflicting information that needs to be corrected.

  • Success- confirmation that: for example, the recording or transmission went through.

  • Reminder- invitation to verify the data, confirm measure or move to the next stage.

Read the instant message and follow the instructions.

Email messages

NEMO can send e-mails for example on Port calls Notifications, delegation, organisation management, system incidents, service breaks and disruptions.

The messages you receive are determined by your permissions, your organisational role and existing notification regulations; (i)

Email messages may include:

  • Timed messagesdispatched: automatically based on a specified date or condition, such as: on expiry of the ship's certificate

  • operational messages;dispatched: as a result of the operator or system function, for example: the organisation invitation or delegation.

Read the message and follow the instructions.

System messages and updates

NEMO can display the user interface for system operation, messages related to service breaks, incidents or changes. Read the messages and work the instructions in them in accordance with the procedure.

NEMO's browser interface will be centrally updated, and not your need to install updates. Future outages and outages the impact changes are reported separately, by email or Nemon system messages.

Because NEMO is used on a browser, browser cache or expired the session can sometimes affect the operation of the user interface. If not updated, shows outdated information or works after update abnormal:

  • first update browser window

  • if problem continues, log out of NEMO and back in

  • clear the browser cache if necessary and open NEMO Again.

The cache need not be emptied regularly. Just do it. if there is a problem or if NEMO's support is given. Note that browsing data or removing cookies can record you also out of other browsers the services you use.

If problem continues, please contact NEMO support via email to NEMO-support@fintraffic.fi
