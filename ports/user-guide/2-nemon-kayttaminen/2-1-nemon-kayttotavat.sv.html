2.1 Användning av Nemo

2.1 Nemo-kanaler

Nemo kan användas för organisatoriska behov och teknisk miljö via en eller flera kanaler. Tillgängliga är:

  • National Port API- anlöp, söka information och fartygsuppgifter i Finland

  • Browser InterfaceNemo grafik användargränssnitt utan systemintegration.

Kanalerna är baserade på samma datamodell och samma koder. Tillgängliga data och aktiviteter kan dock variera: kanal och åtkomsträttigheter.

National Port API

Välj en nationell port API när din hamn vill ta emot och Använd direkt Nemos data i sina egna system. Interface med hamntjänster fartygsdata kan integreras i hamnverksamheten, till exempel system.

hamnorganisationen kan utföra gränssnittsintegrationen själv, eller Använd Data Service Provider (DSP) tjänsteleverantör. DSP fungerar på uppdrag av hamnorganisationen.

DSP får inte ha automatisk tillgång till hamnorganisationens uppgifter och kan utgöra själva organisationens gränssnittskoder. Hamnorganisation bör registreras i Nemo och API bör aktiveras. Port organisation motsvarar kund-ID och kundhemlighet på lämplig hantering och säker leverans DSP används.

Browser Interface

Välj webbläsargränssnitt om din organisation inte behöver integration i sina egna system.

I webbläsargränssnittet kan användare av portorganisationer: granska anlöp till och från deras hamnar; meddelanden och använda den information som lämnas i dem.

Hamnorganisationen ska inte ansvara för rapportering av hamnanrop. Hamnen kan skickaWAR, ATA eller ATD-deklarationendast om överföringen av anmälan delegeras till hamnen.

Snabbmeddelanden

Användargränssnittet kan visa korta snabbmeddelanden från den åtgärd som gjorts resultat eller situation som kräver uppmärksamhet. Snabbmeddelande kan vara relaterat t.ex. sök, ändring av reglering, behandling av data eller driften av systemet.

En av de vanligaste snabbmeddelandena:

  • Missing information- Ett obligatoriskt område är Inte fylld. Fullständig information innan du sparar eller Detta är fallet.

  • Ogiltig informationfältet är ogiltigt eller motstridiga uppgifter som måste korrigeras.

  • FramgångBekräftelse på att: Till exempel gick inspelningen eller överföringen igenom.

  • Påminnelse- inbjudan att verifiera data, bekräfta mäta eller flytta till nästa steg.

Läs snabbmeddelandet och följ instruktionerna.

Systemmeddelanden och uppdateringar

Nemo kan visa användargränssnittet för systemdrift, meddelanden relaterade till tjänsteavbrott, incidenter eller ändringar. Läs meddelandena och arbeta instruktionerna i dem i enlighet med förfarandet.

Nemos webbläsargränssnitt kommer att uppdateras centralt och inte ditt måste installera uppdateringar. Framtida avbrott och avbrott effekterna förändringar rapporteras separat, via e-post eller Nemon systemmeddelanden.

Eftersom Nemo används på en webbläsare, webbläsare cache eller löpt ut sessionen kan ibland påverka driften av användargränssnittet. Om inte uppdaterad, visar föråldrad information eller fungerar efter uppdatering onormal:

  • Första uppdateringen webbläsare fönster

  • Om problemet fortsätter, logga ut från Nemo och tillbaka in i

  • rensa din webbläsare cache om det behövs och öppna Nemo Återigen.

Cache behöver inte tömmas regelbundet. Gör det bara. om det finns ett problem eller om Nemos stöd ges. Observera att surfa data eller ta bort cookies kan registrera dig också från andra webbläsare de tjänster du använder.

Om problemet fortsätter, vänligen kontakta Nemo support via e-post via nemo-support@fintraffic.fi.
