4.1 Statistical reporting

The ports provide monthly port transport statistics and the Agency. New quantitative format for port statistics the notification shall take effect from 1.1.2027.

Port statistics delivery to NEMO

Deliver the statistics monthly. The port can choose announced by Excel file or National Port API - the interface.

Excel file use

Construct statistical data for the reporting month with defined data content Please check the information and send the complete Excel file to: Data acquisition @ traficom.fi.

Read more detailed instructions and file requirements: https: / / fintraffic.vts.github.io / mnsw / ports / port- stattics.html

For the purposes of cross-border reporting: Introduction

The interface notification shall require:

  • the port is registered with NEMO

  • the port organisation has generated client-id and client-secret credentials in the NEMO user interface for use with the API

  • the interface system uses the organisation; assigned codes for the transmission of statistical information.

The content of the information transmitted through the interface corresponds to: data content as defined in the guidance for port statistics. Interface technical information, message structures and responses can be found in the National Port API documentation.

Technical description of the interface: https: / / fintraffic.vts.github.io / mnsw / port / openapi.html # tag / Ports / operation / postStatistics

DSP provider use

If the organisation uses DSP (Data Service Provider) statistical transmission, DSP uses for interface reporting the client- id and client- secret information of the organisation concerned.

Each organisation corresponds to its own client- id and on the transmission of its client- secret data and their updates the DSP it uses. In the event of a change in symbols, the organisation shall: provide the DSP with updated information.

Information to be reported

The statistical declaration shall include: information. Please provide at least the information required by the instructions.

The statistical report shall include, for example:

  • arrival and departure days of the vessel;

  • Vessel identification data

  • whether the ship is in foreign or domestic traffic;

  • if the cargo is in transit (transito)

  • the types and quantities of goods transported by the vessel;

  • type and size of means of transport;

  • Port call identifier (VisitID)

  • cargo direction, i.e. import or export

  • previous and next port of ship

Declaration of the type of goods With HS code

The quality of the goods shall be indicated from 1.1.2027 on the international the HS code according to the customs nomenclature. This differs from the previous the classification of goods in port statistics.

If the existing system or source material uses the current statistical commodity groups, check the correct HS code the correlation table. One current group of goods may have several the corresponding HS code, so select the corresponding specification.
