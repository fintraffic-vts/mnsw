3.1 Port calls

Port call brings together Finland's port or anchorage information on the arrival of the incoming vessel, Being and leaving.

View your port (UN / LOCODE code) Port calls. Port calls appear In the Port calls view where you move to the main menu Port calls selection.

Port calls Review

You can view the Port calls of your port either: cards or listed. Change display mode at the top of the Port calls view buttons.

The list shows the same period of Port calls Table format. The list shows the same basic information as: in the card view as well as the port call identifier, namely Visit ID and the port call status.

Open your Port call details by pressing card or list lines.

To be shown at the port information

The Port call shows:

  • name of vessel and IMO number to be shown after name locks

  • port as UN / LOCODE code

  • the part of the port and / or berth, if indicated;

  • ETA – Estimated Time of Arrival

  • ETD – Estimated Time of Departure

  • to whom the delegated - is displayed if the reporting responsibility for a Port call is transferred to another organisation

  • certain notifications of Port calls and advance information; confirmation in icons. The icons indicate the following notifications: on strengthening:

    • HZA - Dangerous goods declaration on arrival.

    • - SEC, which means port call is SEC declaration (declaration of security).

    • - MDH, which means the port call is MDH declaration issued (ship health declaration).

    • - The SSA, the port call is SSA declaration issued (Ship to ship operation).

    • - the arrow icon of arrival - reports on confirmation of arrival. When Icon Background is green, the Declarant (the organisation that created the Port call) is confirmed that all known information related to the arrival of the vessel: advance information and notifications have been provided;

    • - arrow icon of departure - tells confirmation of the departure. When the icon has a green background, the Declarant (the organisation that created the Port call) has confirmed that: all known pre-departure data; and notifications have been made.

If the arrow icon is grey, this confirmation of the preliminary data is not confirmed. has not yet been done.

Port call status

The status of the Port call indicates the stage of the Port call:

  • Unconfirmed arrival- the ship has been created Port call.

  • Estimated arrival- the arrival of the vessel; prior information has been provided.

  • Port- the actual arrival of the vessel is: notified.

  • Left- the actual departure of the vessel shall be: notified.

  • Cancelled- the port call has been cancelled.

Port calls in Cancelled mode are not visible default in view. You can see them through filtering.

Special case: barges, Tugs and bushes

Barges, tugs and buffers are reported separately in NEMO vessels. Consequently, several separate transport operations may be linked to the same transport. Port calls.

Check the information on each vessel from its own Port call. Barn the cargo transported is shown on the barge's Port call, not by the tug or buggy at the port.

Port calls filtration

You can limit Port calls by switching periods or using more detailed search conditions.

If Port calls do not show as expected, check the selected time period and in use filters.

Period selection

By default, Port calls are shown from day 6 days ahead. If there are no port calls, you'll see the announcement. Your organization has no Port calls.

If you choose a long period of time, downloading Port calls may: lasts longer than usual.

Further details Application conditions

The more detailed filter opens at the top right angle button of the view.

In the opening filter view you can:

  • switch to a specific port operation by entering a Port call; ID or Visit ID

  • limit Port calls to be displayed with different data such as:

    • vessel name or identifier, i.e. IMO number, Call Sign or MMSI number

    • port, i.e. UN / LOCODE or city name

    • start or end of Port call;

    • Port call status;

    • confirmation of arrival or departure data;

    • notification sent to port
