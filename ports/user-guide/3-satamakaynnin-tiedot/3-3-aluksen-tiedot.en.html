3.3 Vessel details

In the Ships view you can search and view NEMO vessels stored in the vessel information service and their data.

Vessel Information Service Data update

The vessel information service shall record permanent vessel data, such as:

  • vessel identifiers

  • General and technical information

  • Ice class information

  • certificates

  • active exemptions.

Data are provided for Port calls of the NEMO vessel notifications. The vessel's data shall be maintained in NEMO, in particular by SID, SHP, CRT and NOA notifications.

The port organisation examines vessel data as a user of information. No more ships at the port. NEMO and does not update their data In the ship view or with SID, SHP, CRT and NOA notifications.

Ship application

Go to the Ship view by selecting the main menu Ships.

Search for one or more of the following information:

  • vessel name

  • IMO number

  • MMSI number

  • call sign

  • other platform identifier (Traficom ID).

In the case of a barge, use another platform identifier for the search: Traficom ID.

Select a vessel from the search results to view it information.

If the vessel is not: found

If the vessel is not found in NEMO's vessel information service, you can notify the notifying organisation responsible for the ship's Port call.

The notifying organisation will add a new vessel to NEMO Port call In the context of the creation. The port organization will not increase the ship or create it. Port call.

If the ship was supposed to be in NEMO by now, but it's not on the right. with search information, contact NEMO's support if necessary at NEMO.support @ fintraffic.fi.

Ice class information

Two different ice class data can be displayed in NEMO:

  1. Ice class established in Finland

  2. Ice class of vessel.

Even if the data show the same ice class code, e.g. IA or IA Super, it's different information.

Finland established ice class

The ice class established in Finland is the Finnish Transport and Communications Agency Information confirmed by Traficom. Traficom confirms the ice class delivered on the basis of documents and the ship's classification marking.

The ice class established in Finland and the net tonnage of the vessel affect: the amount of the fairway fee. The vessel's right to an icebreaking grant is determined by: by ice class and load capacity.

Read more about vessel ice classes on Traficom's website

If the Finnish ice class is missing or not up to date, submit a classification certificate with a CRT notification and request an ice class The Committee of the Regions adopted the following opinion:

Ship Ice class

The ice class of the vessel shall be the ice class granted by the ship classification society or the classification mark. The notification shall be notified by the notifying organisation by means of the SHP notification. field Ice class (DE-009-03).

The data can be used for determining the Finnish ice class data. However, the ice category given by the SHP declaration is not alone be a Finnish ice class established by Traficom.

Both ice class data are visible in the ship's data view. The data for the Port call show the ice class established in Finland.

Ship certificates

In the Certificates section stored on board the certificates are shown as cards.

For example, the following categories of certificates may appear:

  • Tonnage certificate

  • Certificate of nationality

  • Classification certificate

  • Load line certificate

  • Safety certificate

  • Other certificate

The view shows only essential for Finland certificates.

Use Type "Other Certificate" if you give someone else over on the said certificates

The NEMO certificate type code also contains other types of certificate. The certificates to be shown in the view shall be determined by the number of vessels stored on board: on the basis of the information and the classification of evidence used by NEMO.

The certificate information shall be maintained on a ship's Port call: CRT ad.

If no information has been stored in NEMO's vessel information service or the information on the certificate has not been provided by the CRT notification; the certificate appears empty.

The certificate card may show, for example:

  • Date of issue

  • expiry date

  • Issuer

  • Issuer's flag State

  • Issuer name

  • kuvaus.

Open the certificate card to check its details information.

The port cannot add or modify the certificate information. Where the certificate: missing or not up-to-date information, notify the notifying organisation responsible for the Port call.
