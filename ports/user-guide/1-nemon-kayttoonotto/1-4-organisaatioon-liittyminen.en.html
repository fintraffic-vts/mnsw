1.4 Joining an organisation

Conditions of accession

For accession you will need:

  • Sending by an organisation operator email invitation, containing the confirmation code

  • Identification through the Suomi.fi service

The email call confirmation code is valid for 72 hours (3 days) the acceptance. If the invitation expires before accession, ask the administrator to send a new invitation.

This is how you join for the first time
