Data Service Use of Provider (DSP)

The port organisation can use external Data Service Provider (DSP) implementing technical interface integration and NEMO data apply on behalf of the organisation.

DSP will always act as a service provider authorised by the port organisation. The DSP will not automatically have its own access to the port organisation data in NEMO, and DSP cannot request or form itself port organisation API symbols.

If a port organisation uses the DSP, the port organisation shall:

  • be registered in NEMO

  • establish the necessary API for its organisation; and To that end, form a Client ID and a Client Secret (Client) Secret)

  • provide the appropriate API codes to the DSP it uses; safe

  • ensure that the symbols are maintained, renewed and, if necessary, their removal;

DSP uses the interface with the port organisation codes acting on behalf of that organisation. Responsibility for API connection and the management of associated symbols remains: the port organisation.

If Client Secret disappears, is discovered or DSP is terminated, the port organisation must renew or remove the API connection codes; NEMO.

Client ID and Client Secret

Client ID identifies an organisation that: use API. Press Create Connection. to connect The connection cannot be changed manually.

Client Secret works like a secret key couple alongside the Client ID. It is used for API invitations for authenticity.

If the Client Secret is lost, leaked or compromised, The API link must be removed and reestablished, creating a new The Client Secret.
